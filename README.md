# Rakesh Kumar Sahoo — Academic Website

Personal academic website for Rakesh Kumar Sahoo, PhD Scholar at IIT Bhubaneswar.

## Publish with GitHub Pages

1. Create a repository named `rakeshkumarsahoo.github.io`.
2. Upload all files and folders from this project.
3. Commit the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. Your site will be available at `https://rakeshkumarsahoo.github.io/`.

## Before publishing

Replace:
- `assets/images/profile-placeholder.svg` with your photo (or update the image reference).
- `rakeshkumarsahoo1408@gmail.com` with your email.
- Google Scholar and ResearchGate links can be added later; ORCID is already linked.
- Placeholder education entries.
- Placeholder publications.
- Placeholder talks and teaching information.
- Add your CV as `assets/documents/CV.pdf`.

## Notes

The site is plain HTML/CSS/JavaScript, so it works directly with GitHub Pages and does not require a build system.

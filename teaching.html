Autumn 2026–27

Optimization Techniques Lab

M.Sc. — IIT Bhubaneswar

Teaching Assistant

Instructor: Dr. Bankim Chandra Mandal

Course Description

The course covers linear optimization, formulation and geometrical ideas of linear programming problems, simplex method, revised simplex method, duality, sensitivity analysis, transportation and assignment problems. The nonlinear optimization component includes the basic theory of optimization, method of Lagrange multipliers, Karush–Kuhn–Tucker theory, convex optimization, and numerical optimization techniques. Numerical optimization topics include line search methods, gradient methods, Newton's method, conjugate direction methods, quasi-Newton methods, projected gradient methods, and penalty methods.

The laboratory component includes computational assignments implemented in MATLAB.

Spring 2025–26

Numerical Methods

ITEP — IIT Bhubaneswar

Teaching Assistant

Instructor: Prof. T.V.S. Sekhar

Course Description

The course covers sources of numerical errors, round-off errors, truncation errors, floating-point arithmetic, convergence, Gaussian elimination, Gauss–Jordan elimination, Gauss–Seidel method, diagonal dominance, banded matrices, and storage schemes for banded matrices. Other topics include the Newton–Raphson method, local and global minima, rates of convergence, convergence criteria, conjugate gradient method, Taylor series, Euler method, Runge–Kutta methods, and finite difference methods.

Autumn 2025–26

Computer Programming and Data Structures Lab

M.Sc. — IIT Bhubaneswar

Teaching Assistant

Instructor: Prof. Akshay Kumar Ojha

Course Description

The course introduces programming using C, including data types, variables, operators, expressions, statements, control structures, functions, arrays, pointers, recursion, structures, memory management, files, input/output, testing and debugging. Data structures covered include arrays, stacks, queues, linked lists, trees, binary trees, searching and sorting algorithms, including linear search, binary search, insertion sort, bubble sort, and selection sort.

Teaching Philosophy

I believe true mathematical literacy requires understanding the 'why' before the 'how.' Rather than relying on rote formula memorization, my teaching emphasizes core conceptual framework and logical reasoning. Once students master these underlying foundations, they can confidently generalize and apply them to solve any problem.

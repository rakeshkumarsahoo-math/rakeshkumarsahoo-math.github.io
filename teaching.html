AUTUMN 2026–27

Optimization Techniques Lab

Teaching Assistant, M.Sc. — IIT Bhubaneswar

Instructor: Dr. Bankim Chandra Mandal

Course Description

Covers linear and nonlinear optimization, including linear programming, simplex and revised simplex methods, duality, sensitivity analysis, transportation and assignment problems, Lagrange multipliers, KKT conditions, convex optimization, and numerical optimization methods such as line search, gradient, Newton, conjugate direction, quasi-Newton, projected gradient, and penalty methods. Computational assignments are implemented in MATLAB.

SPRING 2025–26

Numerical Methods

Teaching Assistant, ITEP — IIT Bhubaneswar

Instructor: Prof. T.V.S. Sekhar

Course Description

Covers sources of numerical errors, round-off errors, truncation errors, floating-point arithmetic, convergence, Gaussian elimination, Gauss–Jordan elimination, Gauss–Seidel method, diagonal dominance, banded matrices, and storage schemes for banded matrices. Other topics include the Newton–Raphson method, local and global minima, rates of convergence, convergence criteria, conjugate gradient method, Taylor series, Euler method, Runge–Kutta methods, and finite difference methods.

AUTUMN 2025–26

Computer Programming and Data Structures Lab

Teaching Assistant, M.Sc. — IIT Bhubaneswar

Instructor: Prof. Akshay Kumar Ojha

Course Description

Introduces programming using C, covering data types, variables, operators, expressions, control structures, functions, arrays, pointers, recursion, structures, memory management, files, input/output, testing, and debugging. Data structures include arrays, stacks, queues, linked lists, trees, and binary trees, along with searching and sorting algorithms such as linear search, binary search, insertion sort, bubble sort, and selection sort.

Teaching Philosophy

I believe true mathematical literacy requires understanding the “why” before the “how.” Rather than relying on rote formula memorization, my teaching emphasizes core conceptual frameworks and logical reasoning. Once students master these underlying foundations, they can confidently generalize and apply them to solve a wide range of problems.

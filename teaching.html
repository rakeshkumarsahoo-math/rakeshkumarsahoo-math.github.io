Autumn 2026–27

Optimization Techniques Lab

M.Sc. — IIT Bhubaneswar

Teaching Assistant

Instructor: Dr. Bankim Chandra Mandal

Course Description

The course covers linear optimization, formulation and geometrical ideas of linear programming problems, simplex method, revised simplex method, duality, sensitivity analysis, transportation and assignment problems.

The nonlinear optimization component includes the basic theory of optimization, method of Lagrange multipliers, Karush–Kuhn–Tucker theory, convex optimization, and numerical optimization techniques.

Numerical optimization topics include line search methods, gradient methods, Newton's method, conjugate direction methods, quasi-Newton methods, projected gradient methods, and penalty methods.

The laboratory component includes computational assignments implemented in MATLAB.

TA Duties

  • Conducting laboratory/tutorial sessions and assisting students with numerical optimization techniques.
  • Demonstrating the implementation of optimization algorithms in MATLAB.
  • Assisting students with linear programming problems using MATLAB's linprog function.
  • Assisting with nonlinear constrained optimization using fmincon.
  • Demonstrating quadratic programming using quadprog.
  • Preparing and discussing laboratory assignments and practice problems.
  • Helping students understand mathematical formulations, constraints, objective functions, and numerical results.

Spring 2025–26

Numerical Methods

ITEP — IIT Bhubaneswar

Teaching Assistant

Instructor: Prof. T.V.S. Sekhar

Course Description

The course covers sources of numerical errors, round-off errors, truncation errors, floating-point arithmetic, convergence, Gaussian elimination, Gauss–Jordan elimination, Gauss–Seidel method, diagonal dominance, banded matrices, and storage schemes for banded matrices.

Other topics include the Newton–Raphson method, local and global minima, rates of convergence, convergence criteria, conjugate gradient method, Taylor series, Euler method, Runge–Kutta methods, and finite difference methods.

TA Duties

  • Assisting students during numerical methods tutorials.
  • Explaining numerical algorithms and their implementation.
  • Helping students understand convergence and numerical errors.
  • Assisting with computational exercises and programming assignments.
  • Discussing numerical linear algebra techniques and iterative methods.

Computer Programming and Data Structures Lab

M.Sc. — IIT Bhubaneswar

Teaching Assistant

Instructor: Prof. Akshay Kumar Ojha

Course Description

The course introduces programming using C, including data types, variables, operators, expressions, statements, control structures, functions, arrays, pointers, recursion, structures, memory management, files, input/output, testing and debugging.

Data structures covered include arrays, stacks, queues, linked lists, trees, binary trees, searching and sorting algorithms, including linear search, binary search, insertion sort, bubble sort, and selection sort.

TA Duties

  • Assisting students during programming laboratory sessions.
  • Explaining programming concepts and debugging techniques.
  • Helping students implement fundamental data structures.
  • Assisting with programming assignments in C and C++.
  • Guiding students in algorithm implementation and testing.
